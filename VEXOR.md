# VEXOR

VEXOR is a customized Windows account-management UI built from the GPL-3.0 licensed Roblox Account Manager project by ic3w0lf22.

## Download

Open the repository's **Actions** tab, select the latest successful **Build VEXOR for Windows** run, and download the **VEXOR-Windows** artifact. Extract the ZIP and run `VEXOR.exe` with its support files kept beside it.

## Build

GitHub Actions pulls upstream version 3.7.2, applies the VEXOR UI layer, restores the legacy NuGet dependencies, and builds the Release configuration on Windows.

This repository retains the upstream GPL-3.0 licensing requirements. VEXOR does not modify the Roblox client or provide anti-cheat bypass functionality.
